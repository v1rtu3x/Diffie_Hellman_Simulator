# 🛠 Troubleshooting

## Devices offline

* Check WiFi
* Check backend
* Wait for heartbeat

## Build errors

* Ensure ArduinoJson installed

## Session fails

* Timeout → reset
* Disconnect → reconnect device

## GUI not updating

* Check backend running
* Refresh page

## No delay visible

* Check backend logs for:
  STEP_DELAY
  RELAY_DELAY
